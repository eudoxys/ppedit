# Examples

Example cases and data for ppedit, one folder per model. Each folder has
its own `README.md` with the source, license and how its files are made.
Open any case in the editor, for example:

    ppedit serve examples/pypower/case14.glm

| Folder | Contents |
|---|---|
| [`pypower/`](pypower/README.md) | The standard test cases distributed with PYPOWER (`case4gs` to `case300`), and the cvxopf DC line test case `case9_dcline` with a load time series. Each case is there as the original PYPOWER `.py` file and as a GridLAB-D `module pypower` model (`.glm`) written by ppedit. They are regenerated by [`import_pypower_cases.py`](import_pypower_cases.py) in this folder. |
| [`wecc240/`](wecc240/README.md) | The WECC 240-bus system. It starts from the original 2011 PSS/E case from CAISO and NLR. From that come cases for 2011, 2018 and 2020 with geodata, generator costs by type, and EIA-930 balancing-authority areas. The 2020 case also has storage, and August 2020 hourly series of real and reactive load and generator `Pmax`. The folder also has the build scripts and the input data they read. |
| [`ieee118/`](ieee118/README.md) | TODO: an IEEE 118-bus model from the IEEE PES General Meeting 2027 paper submitted by Bennet Meyers in November 2026. Not added yet. |

`import_pypower_cases.py` stays here because it writes into `pypower/`.
Run the scripts from the repository root, for example
`python3 examples/wecc240/build_wecc240_2020.py`.
